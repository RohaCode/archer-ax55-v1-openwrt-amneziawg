# Полноценное пошаговое руководство по прошивке TP-Link Archer AX55 (v1) на OpenWrt из стоковой консоли

Подробное руководство по первичной установке, обновлению и восстановлению кастомной прошивки **OpenWrt 25.12** со встроенной поддержкой **AmneziaWG**, обхода блокировок через **ПодКоп / sing-box**, **Policy-Based Routing (PBR)** и **`dnsmasq-full`** для роутера **TP-Link Archer AX55 v1** (Qualcomm IPQ5018 + свитч Realtek RTL8367S).

> [!CAUTION]
> **ВНИМАНИЕ! Совместимость аппаратных ревизий:**
> Эта сборка OpenWrt поддерживает **только чип свитча RTL8367S**. Часть экземпляров TP-Link Archer AX55 v1 может выходить с чипом **RTL8367D** — для него поддержки в этой сборке нет (драйвер откажется его инициализировать, Ethernet-порты не поднимутся).

---

## 📁 Структура папок с прошивками (`ax55-v1-openwrt/`)

Для вашего удобства файлы разбиты на 4 папки:

1. 📂 **`Stock/` (Стоковые прошивки TP-Link)**
   - `tplink_archer-ax55-v1_telnet.bin` — Модифицированная стоковая прошивка для открытия Telnet-сервера и получения root.
   - `tplink_archer-ax55-v1_original.bin` — Заводская оригинальная прошивка для **полного восстановления к заводскому состоянию**.

2. 📂 **`AmneziaPodkop/` (Максимальная сборка "Всё включено")**
   - Встроены: AmneziaWG, Подкоп (Sing-box), PBR, dnsmasq-full. Для тех, кому нужен обход блокировок по спискам и VPN из коробки.

3. 📂 **`Amnezia/` (Сборка с VPN и PBR)**
   - Встроены: AmneziaWG и PBR (маршрутизация по политикам). Подкоп/Sing-box удалены для экономии памяти. Отличный баланс.

4. 📂 **`ClearOpenWrt/` (Чистая сборка OpenWrt)**
   - Максимально легкая, ванильная сборка OpenWrt. Никаких VPN и PBR. Только необходимые драйверы.

> **ℹ️ Примечание к файлам OpenWrt:**  
> Внутри каждой из трех папок с OpenWrt лежат по два файла:
> - **`..._factory.ubi`** — используется для **первой установки с нуля** поверх стока через Telnet (Шаг 1).
> - **`..._sysupgrade.bin`** — используется для **обновления** уже установленной OpenWrt через веб-интерфейс LuCI (Шаг 9).
>
> 📶 Во всех трех сборках OpenWrt **Wi-Fi сеть включена по умолчанию** (`SSID: OpenWrt`, без пароля).

## 🔑 Шаг 0. Установка прошивки Telnet на стоке и проверка чипа свитча

> **💡 Важное примечание:** Перед установкой OpenWrt необходимо сначала обновить стоковую прошивку роутера через заводской веб-интерфейс TP-Link на специальную версию с включенным Telnet-сервером (`tplink_archer-ax55-v1_telnet.bin`).

1. Подключите ПК кабелем к LAN-порту роутера.
2. Настройте сетевую карту ПК на статический IP: **`192.168.0.10`** (маска `255.255.255.0`).
3. В браузере зайдите в панель управления TP-Link: **`http://192.168.0.1`**.
4. Перейдите в раздел **Дополнительные настройки** ➔ **Система** ➔ **Обновление прошивки** (Firmware Upgrade).
5. Выберите файл **`tplink_archer-ax55-v1_telnet.bin`** (из папки **`Stock`**) и нажмите **Обновить**.
6. Дождитесь перезагрузки роутера (около 2 минут).
7. Откройте командную строку на ПК (PowerShell или CMD) и подключитесь к роутеру по Telnet:

   ```cmd
   telnet 192.168.0.1
   ```

   _(Вы окажетесь в консоли `root` роутера)_.

8. **Проверка модели свитча:**
   В консоли `root` выполните команду:
   ```sh
   find / -iname "*8367*" 2>/dev/null
   ```

   - Если в выводе отображается **`/proc/driver/rtl8367s`** — у вас правильный чип, продолжайте установку ниже!
   - Если в выводе **`rtl8367d`** — стоп! Дальше по этому гайду идти нельзя, прошивку не устанавливайте.

## 🛠️ Шаг 1. Запуск HTTP-сервера на ПК и скачивание файла на роутер

1. **На ПК**: В папке `ax55-v1-openwrt` с файлами прошивки откройте PowerShell и запустите локальный HTTP-сервер Python с биндом к IP ПК:

   ```powershell
   python -m http.server 8000 --bind 192.168.0.10
   ```

   _(Не закрывайте окно PowerShell с запущенным HTTP-сервером до окончания скачивания файла)_.

2. **На роутере (в сессии Telnet)**: Перейдите в папку `/tmp` и скачайте прошивку с ПК:

   ```sh
   cd /tmp
   # Укажите нужную папку в ссылке, например AmneziaPodkop:
   wget http://192.168.0.10:8000/AmneziaPodkop/tplink_archer-ax55-v1_factory.ubi
   ```

3. Проверьте размер скачанного файла:
   ```sh
   ls -la /tmp/tplink_archer-ax55-v1_factory.ubi
   ```
   Размер должен быть около 14.4 МБ _(примерно 14 417 920 байт)_. Если размер значительно меньше — заново проверьте связь и файл на ПК.

---

## 💾 Шаг 2. Определение активного слота и запись

1. Определите, из какого слота загружен сток:

   ```sh
   cat /proc/cmdline | grep -o 'ubi.mtd=[^ ]*'
   ```

2. Запишите файл в противоположный слот:
   - **Если показало `ubi.mtd=rootfs_1` (загружен слот 1):**

     ```sh
     mtd erase rootfs
     mtd write /tmp/tplink_archer-ax55-v1_factory.ubi rootfs
     ```

   - **Если показало `ubi.mtd=rootfs` (загружен слот 0):**
     ```sh
     mtd erase rootfs_1
     mtd write /tmp/tplink_archer-ax55-v1_factory.ubi rootfs_1
     ```
     _(Процесс записи `mtd write` занимает 10–20 секунд, не выключайте роутер!)_

---

## 🔍 Шаг 3. Проверка целостности UBI-тома

Привяжите раздел к UBI _(если шили в rootfs — это mtd11, если в rootfs_1 — mtd12)_:

```sh
ubiattach -m 11
ubinfo -a
```

В выведенном списке тома `kernel`, `rootfs` и `rootfs_data` должны иметь статус **`State: OK`**.

---

## 🔄 Шаг 4. Переключение загрузчика и перезагрузка

1. Укажите конфигурацию и переключите индекс загрузки на прошитый слот:
   - **Если прошивали в rootfs (слот 0):**

     ```sh
     echo '/dev/mtd7 0x0 0x40000 0x00020000 0x2' > /etc/fw_env.config
     fw_setenv tp_boot_idx 0
     ```

   - **Если прошивали в rootfs_1 (слот 1):**
     ```sh
     echo '/dev/mtd7 0x0 0x40000 0x00020000 0x2' > /etc/fw_env.config
     fw_setenv tp_boot_idx 1
     ```

2. Отправьте роутер в перезагрузку:
   ```sh
   reboot
   ```
   > **💡 Примечание о холодном старте:**  
   > На платформах IPQ50xx после команды `reboot` подождите 2–3 минуты, затем **обязательно выключите роутер из розетки на 10 секунд и включите снова**.  
   > _Если после первого выдергивания из розетки роутер не стартовал — сделайте повторное отключение/включение из розетки на 10 секунд, так как холодный старт на этой платформе не всегда инициализируется с первого раза._

---

## 🌐 Шаг 5. Первый вход в OpenWrt

1. Подождите 2–3 минуты для первичной инициализации файловой системы.
2. Переведите сетевую карту ПК в режим **DHCP (Автоматический IP)**.
3. В браузере перейдите по адресу **`http://192.168.1.1`**, введите стандартный пароль **`passwd`** и нажмите **Login**.
4. Задайте собственный пароль администратора в меню **System** ➔ **Administration**.

---

## 📶 Шаг 6. Настройка Wi-Fi сети через консоль SSH (Smart Connect + Wi-Fi 6)

Настройка единой бесшовной сети Wi-Fi (2.4 ГГц + 5 ГГц в режиме Wi-Fi 6 HE80) с надёжным шифрованием `WPA2-PSK [AES]` (`psk2+ccmp`) для 100% совместимости с любыми смартфонами и Mesh-системами (включая Mercusys Halo).

> **💡 Примечание:** Во всех сборках Wi-Fi уже включен по умолчанию (сеть `OpenWrt` без пароля). Если вы хотите задать свое собственное имя сети и пароль, выполните следующие шаги:

1. Подключитесь к роутеру по SSH:

   ```powershell
   ssh root@192.168.1.1
   ```

   _(Если появится предупреждение безопасности `HOST IDENTIFICATION HAS CHANGED`, выполните на ПК команду `ssh-keygen -R 192.168.1.1`)_.

2. Скопируйте и выполните в консоли SSH готовый блок (укажите ваше имя сети и пароль):

   ```sh
   uci set wireless.default_radio0.disabled='0'
   uci set wireless.default_radio0.ssid='ИМЯ_ВАШЕЙ_СЕТИ'
   uci set wireless.default_radio0.encryption='psk2+ccmp'
   uci set wireless.default_radio0.key='ВАШ_ПАРОЛЬ'

   uci set wireless.default_radio1.disabled='0'
   uci set wireless.default_radio1.ssid='ИМЯ_ВАШЕЙ_СЕТИ'
   uci set wireless.default_radio1.encryption='psk2+ccmp'
   uci set wireless.default_radio1.key='ВАШ_ПАРОЛЬ'
   uci set wireless.radio1.htmode='HE80'

   uci commit wireless
   wifi reload
   ```

## 🛡️ Шаг 7. Настройка и запуск AmneziaWG + PBR (Выборочный VPN)

> **💡 Важное примечание:** По умолчанию служба Policy-Based Routing (PBR) в OpenWrt выключена (`enabled='0'`). Чтобы маршрутизатор не выдавал ошибку `ERROR: The pbr service is currently disabled!`, обязательно включаем службу командой `uci set pbr.config.enabled='1'`.

Скопируйте в консоль SSH этот 100% рабочий блок команд:

```sh
cat << 'EOF' >> /etc/config/network

config interface 'awg0'
        option proto 'amneziawg'
        option private_key 'ВАШ_ПРИВАТНЫЙ_КЛЮЧ'
        list addresses '10.8.0.100/32'
        option awg_jc '4'
        option awg_jmin '40'
        option awg_jmax '70'
        option awg_s1 '5'
        option awg_s2 '10'
        option awg_h1 '1'
        option awg_h2 '2'
        option awg_h3 '3'
        option awg_h4 '4'

config amneziawg_awg0
        option public_key 'ПУБЛИЧНЫЙ_КЛЮЧ_СЕРВЕРА'
        option endpoint_host 'IP_АДРЕС_СЕРВЕРА'
        option endpoint_port '51820'
        option persistent_keepalive '25'
        option route_allowed_ips '0'
        list allowed_ips '0.0.0.0/0'
EOF

# Добавляем awg0 в фаервол wan
uci set firewall.@zone[1].network='wan wan6 awg0'
uci commit firewall

# Активируем службу PBR, добавляем awg0 и настраиваем правило для Smart TV
uci set pbr.config.enabled='1'
uci add_list pbr.config.supported_interface='awg0'
uci add pbr policy
uci set pbr.@policy[-1].name='tv_vpn'
uci set pbr.@policy[-1].src_addr='IP_АДРЕС_ТЕЛЕВИЗОРА'   # Например: 192.168.1.104
uci set pbr.@policy[-1].interface='awg0'

uci commit pbr

# Перезапускаем все службы
/etc/init.d/network restart
/etc/init.d/firewall restart
/etc/init.d/pbr enable
/etc/init.d/pbr restart
ifup awg0
```

Проверка соединения:

```sh
awg show
```

_(В выводе появится `latest handshake: X seconds ago` и прием/отдача байт)_.

## 🚇 Шаг 8. Установка и настройка Подкопа (Обход блокировок по спискам)

Подкоп позволяет прозрачно обходить блокировки (YouTube, Discord, Instagram и т.д.) только для нужных сайтов, не пуская весь остальной трафик через VPN.

Поскольку ядро обхода `sing-box` (весом ~40 МБ) уже аппаратно вшито и сжато в нашей сборке для экономии памяти, установка графического интерфейса происходит мгновенно и без ошибок "No space left on device".

1. Подключитесь по SSH к роутеру:

   ```bash
   ssh root@192.168.1.1
   ```

2. Выполните следующие команды по очереди:

   ```bash
   # 1. Скачиваем скрипт установки
   wget -O /tmp/install.sh https://raw.githubusercontent.com/itdoginfo/podkop/refs/heads/main/install.sh

   # 2. Вырезаем из него проверку свободного места (т.к. sing-box уже установлен в ядре)
   sed -i 's/15360/1000/g' /tmp/install.sh

   # 3. Удаляем мертвую ссылку на кастомный репозиторий AmneziaWG (во избежание ошибок apk update)
   sed -i '/amneziawg/d' /etc/apk/repositories.d/*.list 2>/dev/null

   # 4. Запускаем установку
   sh /tmp/install.sh

   # 5. Убираем за собой установочный скрипт
   rm -f /tmp/install.sh

   # 6. Очищаем кэш веб-интерфейса (чтобы меню обновилось без перезагрузки роутера)
   rm -rf /tmp/luci-*
   ```

3. После установки обновите страницу веб-интерфейса роутера в браузере (клавиша **F5**), и в верхнем меню появится раздел **Подкоп**. Зайдите туда, добавьте свой прокси-ключ (VLESS/Shadowsocks) или настройте маршрутизацию через созданный ранее интерфейс `awg0` (AmneziaWG).

## 🔄 Шаг 9. Обновление прошивки OpenWrt через веб-интерфейс (`sysupgrade.bin`)

> **💡 Применяется только если на роутере УЖЕ установлена прошивка OpenWrt** и вам необходимо обновить её на новую версию.

1. Зайдите в веб-интерфейс роутера: **`http://192.168.1.1`**.
2. Перейдите в меню: **System** ➔ **Flash Firmware** (Система ➔ Прошивка).
3. В строке **Flash new firmware image** нажмите синюю кнопку **Flash image...**.
4. Выберите файл **`tplink_archer-ax55-v1_sysupgrade.bin`**.
5. Нажмите **Upload** ➔ **Continue** _(галочка "Keep settings / Сохранить настройки" по умолчанию включена)_.
6. **ВАЖНОЕ ПРИМЕЧАНИЕ О ПАУЗЕ И ПЕРЕЗАГРУЗКЕ ПО ПИТАНИЮ:**
   - При обновлении через веб-интерфейс фоновая запись блоков в память продолжается дольше. После нажатия кнопки **Continue** подождите **не менее 4–5 минут** (наверняка, чтобы процесс перезаписи флеш-памяти 100% завершился).
   - После этого **выключите роутер из розетки на 10 секунд и включите снова**.
   - _Если после первого включения роутер не отозвался — выньте штекер питания из розетки еще раз на 10 секунд и включите снова (холодный старт на IPQ50xx иногда требует повторного сброса питания)._

## 🔙 Шаг 10. Полный откат на оригинальную заводскую прошивку TP-Link (`original.bin`)

### Способ 1. Быстрый переключатель слота из SSH (Если OpenWrt работает)

Поскольку оригинальная прошивка TP-Link сохранилась в соседнем слоте памяти:

1. Подключитесь по SSH к роутеру: `ssh root@192.168.1.1`.
2. Выполните команду переключения загрузчика на заводской слот:
   ```sh
   echo '/dev/mtd7 0x0 0x40000 0x00020000 0x2' > /etc/fw_env.config
   fw_setenv tp_boot_idx 1
   reboot
   ```
3. Подождите 2–3 минуты, **выключите роутер из розетки на 10 секунд и включите снова**. Загрузится оригинальный сток TP-Link по адресу `http://192.168.0.1`!

### Способ 2. Заводское восстановление через U-Boot Web Recovery (`tplink_archer-ax55-v1_original.bin`)

Если нужно гарантированно перезаписать флеш-память чистым оригинальным файлом:

1. На ПК задайте статический IP: **`192.168.0.10`** (маска `255.255.255.0`, шлюз `192.168.0.1`).
2. Отключите штекер питания из роутера.
3. Зажмите скрепкой/булавкой кнопку **Reset** сзади роутера и, **не отпуская её**, вставьте штекер питания обратно.
4. Удерживайте кнопку Reset нажатой **15–20 секунд**, пока индикатор питания на роутере не загорится **КРАСНЫМ** цветом (сигнал перехода в аварийный режим U-Boot Web Recovery).
5. Откройте браузер на ПК и перейдите по адресу: **`http://192.168.0.1`** _(откроется меню TP-Link Firmware Recovery)_.
6. Выберите файл **`tplink_archer-ax55-v1_original.bin`** (из папки **`Stock`**) и нажмите **Upgrade**.
7. Дождитесь 3–5 минут завершения прошивки, переведите ПК в режим DHCP (Автоматический IP) и зайдите на стоковый интерфейс по адресу **`http://192.168.0.1`**.
